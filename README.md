# 📊 Product Sales Analysis & Power BI Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales performance, profitability, customer discounts, product quantity, and customer-level performance.

The dashboard transforms sales data into interactive visualizations and KPIs to make business performance easier to understand and analyze.

## 🎯 Project Objectives

- Analyze overall profit and quantity
- Identify customers receiving the highest discounts
- Analyze profit distribution across different discount levels
- Analyze sales performance based on quantity
- Compare customer-level performance
- Create an interactive and easy-to-understand business dashboard

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization
- Business Intelligence
- Interactive Dashboard Design

## 📈 Dashboard Features

### Key Performance Indicators

- Total Profit
- Total Quantity
- Postal Code / Customer-related information

### Visualizations

- Top 10 Customers by Discount
- Top 10 Profit by Discount
- Top 10 Sales by Quantity
- Customer-level detailed report
- Interactive customer filters

## 🔍 Analysis Performed

The dashboard allows users to explore:

- Which customers have the highest discounts
- How profit is distributed across different discount levels
- Which products/customers contribute to sales quantity
- Customer-level profit and quantity
- Detailed order-level information
